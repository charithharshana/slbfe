# SLBFE Interview English Lessons

This repository contains the source lessons and the static website for the SLBFE
interview-English practice materials.

## Website

The public website is built from the `html/` directory and is published with
GitHub Pages. The entry point is `html/index.html`.

## Local preview

From the repository root, run:

```bash
python -m http.server 8000 --directory html
```

Then open `http://localhost:8000` in a browser.
